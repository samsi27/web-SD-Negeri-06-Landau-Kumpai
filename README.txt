WEBSITE SDN 01 LANDAU KUMPAI — PROYEK PEMBELAJARAN

Cara menjalankan:
1. Ekstrak file ZIP.
2. Buka folder website-sdn-landau-kumpai di VS Code.
3. Buka index.html di browser, atau klik kanan index.html dan pilih Open with Live Server jika ekstensi Live Server sudah dipasang.
4. Klik menu navigasi untuk membuka halaman lain.

Website ini menggunakan HTML dan CSS tanpa framework. Pengunjung tidak perlu login.
Untuk memublikasikan ke internet, unggah file ke layanan hosting statis seperti GitHub Pages.

PENTING:
- Foto yang tampil dari internet merupakan gambar contoh. Ganti dengan foto sekolah yang asli dan boleh dipublikasikan.
- Lengkapi sejarah, visi, misi, data guru, jadwal, persyaratan PPDB, dan kontak berdasarkan informasi resmi sekolah.
- Jangan mengunggah data pribadi siswa atau dokumen internal yang tidak ditujukan untuk publik.
